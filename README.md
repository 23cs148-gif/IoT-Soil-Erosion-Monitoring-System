# IoT-Based Soil Erosion and Land Degradation Monitoring System

## Project Overview
An IoT-based monitoring system designed to monitor soil conditions and identify potential soil erosion and land degradation using ESP32 and environmental sensors.

## Technologies Used
- ESP32
- Soil Moisture Sensor
- Rain Sensor
- Arduino IDE
- Embedded C/C++
- Blynk IoT
- Wi-Fi

## Features
- Real-time soil moisture monitoring.
- Rainfall detection.
- Monitoring of critical soil conditions.
- LED and buzzer alerts.
- Remote monitoring through Blynk IoT.

## Working
The ESP32 collects data from the soil moisture and rain sensors. The collected information is processed to identify critical conditions. When the configured threshold is reached, LED and buzzer alerts are activated, and the readings are sent to the Blynk IoT platform.

## Objective
To provide a low-cost and accessible soil monitoring solution that helps small-scale farmers monitor soil conditions.
